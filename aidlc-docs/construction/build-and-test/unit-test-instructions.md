# Unit Test Instructions

> PoC 프로젝트로 자동화된 테스트 프레임워크 없이, User Story 기반 수동 테스트 체크리스트를 제공합니다.
> `npm run dev`로 서버를 실행한 후 http://localhost:5173 에서 테스트하세요.

## US-1: 회원가입

- [ ] 이메일과 비밀번호(6자 이상) 입력 후 회원가입 → 로그인 페이지로 이동
- [ ] 이미 가입된 이메일로 가입 시도 → "이미 사용 중인 이메일입니다" 에러 표시
- [ ] 이메일 형식 오류 (예: `test`) → 에러 메시지 표시
- [ ] 비밀번호 6자 미만 입력 → "비밀번호는 6자 이상이어야 합니다" 에러 표시
- [ ] 이메일 또는 비밀번호 빈칸 → 에러 메시지 표시

## US-2: 로그인

- [ ] 올바른 이메일/비밀번호 입력 → TODO 목록 페이지로 이동
- [ ] 잘못된 비밀번호 입력 → "이메일 또는 비밀번호가 올바르지 않습니다" 에러 표시
- [ ] 존재하지 않는 이메일 입력 → 동일 에러 메시지 표시
- [ ] 로그인하지 않은 상태에서 http://localhost:5173/ 접근 → 로그인 페이지로 리다이렉트

## US-3: 로그아웃

- [ ] 로그아웃 버튼 클릭 → 로그인 페이지로 이동
- [ ] 로그아웃 후 http://localhost:5173/ 접근 → 로그인 페이지로 리다이렉트

## US-4: TODO 추가

- [ ] 제목 입력 후 추가 버튼 클릭 → 목록에 새 항목 표시, 미완료 상태
- [ ] 추가 후 입력 필드가 비워짐
- [ ] 빈 제목으로 추가 시도 → "제목을 입력해주세요" 에러 표시

## US-5: TODO 목록 조회

- [ ] 로그인 후 내가 추가한 TODO만 표시됨
- [ ] 다른 계정으로 로그인 시 해당 계정의 TODO만 표시됨
- [ ] TODO가 없으면 "할 일이 없습니다" 메시지 표시

## US-6: TODO 수정

- [ ] 수정 버튼 클릭 → 편집 모드 진입 (입력 필드 표시)
- [ ] 제목 변경 후 저장 → 변경된 제목 반영
- [ ] 빈 제목으로 저장 시도 → 저장되지 않음
- [ ] 취소 버튼 클릭 → 원래 제목 유지

## US-7: TODO 삭제

- [ ] 삭제 버튼 클릭 → 해당 항목 목록에서 제거
- [ ] 페이지 새로고침 후에도 삭제된 항목 없음

## US-8: 완료/미완료 토글

- [ ] 체크박스 클릭 → 완료 상태로 전환, 취소선 표시
- [ ] 완료된 항목 체크박스 다시 클릭 → 미완료로 전환, 취소선 제거
- [ ] 페이지 새로고침 후에도 상태 유지

## US-9: 필터링

- [ ] "전체" 필터 → 모든 TODO 표시
- [ ] "완료" 필터 → 완료된 항목만 표시
- [ ] "미완료" 필터 → 미완료 항목만 표시
- [ ] 현재 선택된 필터 버튼이 시각적으로 구분됨
- [ ] 필터 결과가 없으면 "할 일이 없습니다" 메시지 표시
