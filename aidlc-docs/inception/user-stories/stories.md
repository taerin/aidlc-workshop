# User Stories

> 분류: User Journey 기반 | 페르소나: 김민수 (바쁜 직장인)
> 완성 기준: 핵심 동작 + 주요 에러 케이스

---

## Journey 1: 회원가입

### US-1: 회원가입
**As a** 새로운 사용자,
**I want to** 이메일과 비밀번호로 회원가입하고 싶다,
**So that** 내 TODO 데이터를 안전하게 관리할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 이메일과 비밀번호를 입력하고 가입 버튼을 누르면 계정이 생성된다
- 가입 성공 시 로그인 페이지로 이동한다
- 이미 가입된 이메일로 가입 시도 시 "이미 사용 중인 이메일입니다" 에러가 표시된다
- 이메일 형식이 올바르지 않으면 에러 메시지가 표시된다
- 비밀번호가 너무 짧으면 (6자 미만) 에러 메시지가 표시된다

---

## Journey 2: 로그인 / 로그아웃

### US-2: 로그인
**As a** 가입된 사용자,
**I want to** 이메일과 비밀번호로 로그인하고 싶다,
**So that** 내 TODO 목록에 접근할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 올바른 이메일/비밀번호 입력 시 TODO 목록 페이지로 이동한다
- 잘못된 이메일 또는 비밀번호 입력 시 "이메일 또는 비밀번호가 올바르지 않습니다" 에러가 표시된다
- 로그인하지 않은 상태에서 TODO 페이지 접근 시 로그인 페이지로 리다이렉트된다

### US-3: 로그아웃
**As a** 로그인된 사용자,
**I want to** 로그아웃하고 싶다,
**So that** 다른 사람이 내 TODO를 볼 수 없다.

**Persona**: 김민수

**Acceptance Criteria**:
- 로그아웃 버튼 클릭 시 로그인 페이지로 이동한다
- 로그아웃 후 TODO 페이지에 접근할 수 없다

---

## Journey 3: TODO 추가

### US-4: TODO 항목 추가
**As a** 로그인된 사용자,
**I want to** 새로운 할 일을 추가하고 싶다,
**So that** 해야 할 업무를 기록할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 제목을 입력하고 추가 버튼을 누르면 TODO 목록에 새 항목이 나타난다
- 추가된 항목은 미완료 상태로 생성된다
- 빈 제목으로 추가 시도 시 에러 메시지가 표시된다
- 추가 후 입력 필드가 비워진다

---

## Journey 4: TODO 조회 및 관리

### US-5: TODO 목록 조회
**As a** 로그인된 사용자,
**I want to** 내 TODO 목록을 볼 수 있다,
**So that** 해야 할 일을 한눈에 파악할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 로그인 후 내가 추가한 TODO 항목들만 표시된다
- 다른 사용자의 TODO는 보이지 않는다
- TODO가 없으면 빈 상태 안내 메시지가 표시된다

### US-6: TODO 항목 수정
**As a** 로그인된 사용자,
**I want to** 기존 TODO의 제목을 수정하고 싶다,
**So that** 잘못 입력한 내용을 고칠 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- TODO 항목의 제목을 클릭하거나 수정 버튼으로 편집 모드에 진입한다
- 수정 후 저장하면 변경된 제목이 반영된다
- 빈 제목으로 수정 시도 시 에러 메시지가 표시된다
- 수정 취소 시 원래 제목이 유지된다

### US-7: TODO 항목 삭제
**As a** 로그인된 사용자,
**I want to** 불필요한 TODO를 삭제하고 싶다,
**So that** 목록을 깔끔하게 유지할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 삭제 버튼 클릭 시 해당 항목이 목록에서 제거된다
- 삭제된 항목은 복구할 수 없다

---

## Journey 5: TODO 완료 관리

### US-8: TODO 완료/미완료 토글
**As a** 로그인된 사용자,
**I want to** TODO의 완료 상태를 토글하고 싶다,
**So that** 끝낸 일과 남은 일을 구분할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- 체크박스 클릭 시 완료/미완료 상태가 전환된다
- 완료된 항목은 취소선으로 시각적으로 구분된다
- 상태 변경은 즉시 저장된다

---

## Journey 6: TODO 필터링

### US-9: TODO 필터링
**As a** 로그인된 사용자,
**I want to** TODO를 전체/완료/미완료로 필터링하고 싶다,
**So that** 남은 할 일에 집중할 수 있다.

**Persona**: 김민수

**Acceptance Criteria**:
- "전체" 필터 선택 시 모든 TODO가 표시된다
- "완료" 필터 선택 시 완료된 항목만 표시된다
- "미완료" 필터 선택 시 미완료 항목만 표시된다
- 현재 선택된 필터가 시각적으로 구분된다
- 필터 결과가 없으면 안내 메시지가 표시된다
