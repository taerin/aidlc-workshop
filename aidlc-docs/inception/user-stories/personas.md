# User Personas

## Persona 1: 김민수 (바쁜 직장인)

| 항목 | 내용 |
|------|------|
| **이름** | 김민수 |
| **나이** | 32세 |
| **직업** | IT 회사 마케팅 매니저 |
| **기술 수준** | 중급 — 웹 서비스 사용에 익숙 |

### 특성
- 하루에 처리할 업무가 10~20개씩 쌓임
- 회의 사이사이 짧은 시간에 할 일을 정리하고 싶음
- 빠른 입력과 직관적인 UI를 선호
- 완료한 일을 체크하면서 성취감을 느끼고 싶음

### 목표
- 업무 할 일을 빠르게 추가하고 관리
- 완료/미완료를 한눈에 파악
- 남은 할 일에 집중하기 위해 필터링 활용

### 불만 (Pain Points)
- 복잡한 프로젝트 관리 도구는 오버스펙
- 매번 로그인하기 귀찮지만, 다른 사람이 내 할 일을 보는 건 싫음
- 느린 로딩이나 불필요한 단계가 있으면 바로 이탈

### 사용 시나리오
1. 아침 출근 후 오늘 할 일을 빠르게 입력
2. 회의 끝나고 완료된 항목 체크
3. 퇴근 전 미완료 항목 필터링으로 남은 일 확인
