# AI-DLC 개인화 규칙

> 이 규칙은 core-workflow.md의 기본 동작을 오버라이드합니다.

## 1. 대화형 Q&A 우선
- 질문을 .md 파일에 작성하지 말고 **채팅으로 하나씩 질문**한다
- 사용자 답변은 대화 후 .md 파일에 일괄 기록한다 (기록용)
- 파일 기반 Q&A는 사용자가 명시적으로 요청할 때만 사용

## 2. 쉬운 언어 사용
- 전문 용어를 그대로 쓰지 않는다
- 쉬운 한국어로 먼저 설명하고, 전문 용어는 괄호 안에 표기
- 예: "각 기능의 완성 기준 (Acceptance Criteria)"

## 3. 매 질문에 AI 추천 필수
- 선택지를 제시할 때 **반드시 추천 + 이유**를 함께 제공
- 형식: `💡 추천: [선택지] — [이유]`
- 사용자가 빠르게 판단할 수 있도록 한다

## 4. 승인 게이트 최소화
- **자동 진행**: Workspace Detection, 모순 없는 답변 분석, 문서 생성
- **승인 필요**: Requirements, User Stories, Workflow Planning, Application Design, Code Generation Plan
- 승인 요청 시 반드시 **"승인하면 X를 합니다"**를 먼저 설명한 후 승인을 요청

## 5. 단계 건너뛰기 판단 강화
- PoC/프로토타입이라도 **사용자 플로우가 존재하면 User Stories를 실행**
- 단계를 건너뛸 때는 기계적 판단(PoC=단순)이 아닌 **실제 기능 복잡도**를 기준으로 판단
- 인증, 다중 화면, 상태 관리가 있으면 "단순"으로 분류하지 않는다

## 6. 단계 완료 시 자동 커밋
- 각 AIDLC 단계가 완료되면 자동으로 git commit + push
- 커밋 메시지 형식: `[PHASE]: [Stage] complete - [간단한 설명]`
